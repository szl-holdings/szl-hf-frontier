# SZL TypeSafe Triage

> **REFERENCE ARTIFACT · BLOCKED · NOT PROMOTABLE**
>
> This public LoRA adapter exists for transparency, reproducibility, and inspection of the triage harness. It is **not approved for deployment, promotion, production use, safety-critical use, or customer-facing triage**.

## What it does

This adapter is a governed triage classifier built on `Qwen/Qwen3.5-0.8B-Base`. It is designed to emit strict JSON with fields such as:

```json
{"label":"...","state":"...","evidence":["..."]}
```

Its intended behavior is to:

- Propose a structured classification label.
- Return `state="REVIEW"` rather than overclaim when evidence is thin or competing labels are equally supported.
- Preserve refusal behavior when a prompt attempts to instruct the classifier instead of describing the problem.
- Support inspection of a governed-classification harness.

## What it does not do

- It is not promotable or deployment-approved.
- It is not a cleared production classifier.
- It is not validated for customer-facing or safety-critical triage.
- It does not turn a behavioral gate result into a release decision.
- It does not establish general performance beyond the documented reference run.
