## GitHub-aligned Python

An earlier version of this card embedded a code block that stopped mid-statement (`if trainer.state.log_hi`) and that did not match the `receipted_unsloth.py` actually stored on this Hub ID (it showed an older 2,932-byte single-profile variant with `--base/--r/--seed` flags, which still exists as `atelier/receipted_unsloth.py` in szl-khipu and szl-forge). That block is removed. What follows is quoted verbatim from the 12,165-byte `receipted_unsloth.py` on this repository (2026-09-25 read).

Usage lines from the module docstring:

```text
  python receipted_unsloth.py --profile willay --receipt-only
  python receipted_unsloth.py --profile chaski --data doctrine.jsonl --out out/chaski
```

The receipt-minting tail of `main()` — the point of the file: every knob lands in `training_receipt.json`, loss is read from the trainer log, and the envelope is meant to be signed before any merge:

```python
    trainer = SFTTrainer(model=model, tokenizer=tokenizer, train_dataset=ds, args=SFTConfig(**sft_kw))
    t0 = time.time()
    trainer.train()
    Path(args.out).mkdir(parents=True, exist_ok=True)
    model.save_pretrained(args.out)
    loss = None
    if trainer.state.log_history:
        last = trainer.state.log_history[-1]
        loss = last.get("train_loss") or last.get("loss")
    extra.update({"final_loss": loss, "seconds": round(time.time() - t0, 3), "honesty": "REPORTED"})
    rec = mint_receipt(args.profile, cfg, extra)
    Path(args.out, "training_receipt.json").write_text(json.dumps(rec, indent=2) + "\n")
    print(json.dumps(rec, indent=2))
    return 0
```

`mint_receipt` refuses `proven_trust: true` and refuses any non-null `energy_j` ("refusing to fabricate joules"); the receipt records `"gguf": "derived — never the signed object"`. Read the full file on this repository or in the canonical kit linked above; do not treat this excerpt as the whole program.
