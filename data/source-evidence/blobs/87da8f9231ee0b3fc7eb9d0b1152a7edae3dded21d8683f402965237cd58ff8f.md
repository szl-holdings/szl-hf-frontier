# SZL Readiness Runs

Signed Khipu receipts emitted by the eight SZL Production-Readiness agents.
Doctrine **v11 (LOCKED): 749 / 14 / 163**.

## Layout
```
receipts/<agent>/<UTC-date>/<UTC-timestamp>.json   # one DSSE envelope per run
dr-dumps/<flagship>/<ts>.ndjson                    # READINESS-DR backup dumps
```

Agents: `readiness-reliability`, `readiness-security`, `readiness-observability`,
`readiness-operability`, `readiness-compliance`, `readiness-docs`, `readiness-dr`,
`readiness-audit-rift` (the verifier of verifiers).

Each receipt is a DSSE-style envelope over a canonical JSON payload, Ed25519-signed
with the fleet key. Envelopes with `"signed": false` are honestly unsigned (no key
was available at run time) — never a fabricated signature.

## Load it

Each run is a standalone DSSE-envelope JSON file (`{payloadType, payload, payloadSha256, signatures, signed}`), nested `receipts/<agent>/<date>/<ts>.json`. A `receipts` config globs every run into one table via the `json` builder:

```python
from datasets import load_dataset

ds = load_dataset("SZLHOLDINGS/readiness-runs", "receipts", split="train")
print(ds[0])   # {payloadType, payload (base64), payloadSha256, signatures, signed}
# payload is base64-encoded canonical JSON:
import base64, json
print(json.loads(base64.b64decode(ds[0]["payload"])))
```

If the nested one-file-per-run layout does not resolve cleanly in your `datasets` version, pull the raw files directly — this always works:

```python
import base64, glob, json
from huggingface_hub import snapshot_download

local = snapshot_download("SZLHOLDINGS/readiness-runs", repo_type="dataset",
                          allow_patterns=["receipts/**/*.json"])
for path in glob.glob(f"{local}/receipts/**/*.json", recursive=True):
    env = json.load(open(path))
    run = json.loads(base64.b64decode(env["payload"]))
    print(run["agent"], run["emitted_at_utc"], "signed=" + str(env["signed"]))
```

> **Note:** the `configs:` entry above is a minimal `json`-builder glob over the nested receipts. Per-field payload typing is not yet declared (payloads are base64-encoded canonical JSON, decoded as shown) — a typed loader script is a pending TODO.
