## Stable identifiers and record schema

Node IDs are namespaced and deterministic:

- `estate:{estates[].name}`
- `vertical:{verticals[].id}`
- `hub:{hubs object key}`
- `substrate:{repository basename}`

Each node record has `id`, `type`, `key`, `label`, and type-specific
`attributes`. Each edge record has `id`, `type`, `source`, `target`,
`traversal`, and `derivation`; `wired-into` edges also include
`match_reasons`. Edge IDs are:

```text
edge:{type}:{source}->{target}
```

`source` and `target` retain the semantic direction of the derivation, while
`traversal` is always `undirected`, as in the Constellation BFS engine. Every
edge also carries a unique, contiguous `engine_order`; consumers sort incident
edges by that field before BFS to reproduce the pinned engine's shortest-path
tie-break. `schema.json` is the strict JSON Schema for `graph.json`.

## Files

- `nodes.jsonl` and `edges.jsonl`: compact UTF-8 JSON Lines, lexically sorted by ID.
- `graph.json`: self-contained graph with nodes, edges, counts, semantics, and provenance.
- `schema.json`: JSON Schema 2020-12 contract for `graph.json`.
- `sources/`: exact fetched source bytes.
- `generator.py`: standard-library-only deterministic builder and fail-closed validator.
- `receipt.json`: per-file SHA-256/byte manifest plus canonical receipt payload hash.
- `SHA256SUMS`: hashes all receipted files and `receipt.json` itself.

The publication tree is exactly the ten files listed by the validator. A local
root `.incoming/` directory may hold tests or staging material and is explicitly
excluded from publication inventory; no other extra file, symlink, junction, or
reparse point is accepted.

## Build and verify

From this directory in PowerShell, using the bundled Codex Python runtime:

```powershell
$py = 'C:\Users\steph\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $py -I -B .\generator.py build --source-dir .\sources --output-dir .
& $py -I -B .\generator.py validate --dataset-dir .
```

The builder fails closed if the source counts or derived edge counts drift from
this v1 contract. To independently recompute any file hash:

```powershell
Get-FileHash -Algorithm SHA256 .\graph.json
```

The validator checks pinned source bytes and field types, strict graph-schema
conformance, counts, endpoint integrity, lexical ID ordering, canonical BFS
order, graph connectivity, an independently reconstructed receipt and exact
receipt file set, Windows-safe path containment, the exact ten-file publication
tree, and every `SHA256SUMS` entry.
